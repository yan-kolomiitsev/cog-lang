Get started with Cog

Work through these small programs to learn the basics. Edit an example and choose Run, or press Ctrl+Enter / Command+Enter in its editor.

Run this tutorial locally

Requires Rust 1.95 or newer, Cargo, and Node.js 24.12 or newer. From the Cog repository:

node web/server.mts

The server builds Cog and prints a local URL. Open that URL to run examples with the actual compiler and VM. No npm installation is needed. If Cargo dependencies are not cached, run cargo build --locked --bin cog first.

For a standalone program: save the source as main.cog, then run cargo run --locked --bin cog -- run main.cog.

Start the local server to run examples. You can still read and edit them here.

3. Types, nil, and conversion
The basic annotations are int, float, bool, str, and nil. A suffix ? allows nil as a normal value. Use as for explicit conversion; a failed conversion produces Error.

4. Functions and block results
The last expression without a semicolon is the block result. A block without a tail returns nil. Functions can declare a result with -> T. Arguments can have defaults; positional arguments go before named ones.

6. Arrays and shared values
Arrays use zero-based indexing. array << value appends, value >> array prepends, and both mutate the array. Assignment shares the array: a const view observes changes made through an existing mutable binding.

Plain strings keep braces literally. Use $"...{expression}..." for interpolation and {{ / }} for literal braces inside it. read_line reads a line from stdin; str::trim removes surrounding whitespace.

9. Errors and cleanup
?? chooses a fallback for nil; ?! chooses one for Error. try/catch observes an unhandled Error in its lexical body. Postfix !! returns an Error from the current function through cleanup, bypassing its local catches. defer runs cleanup when its scope is exited.

Next: modules and projects
Use cog init my-app to create a project. Modules follow source filenames; use imports names and public exposes declarations to other modules.
Try the modules example and package inclusion example, then read the project guide. The language reference covers further details and current limitations.
This tutorial uses implemented syntax. Typed arrays, scalar/struct compile-time evaluation, type aliases, extension methods, inferred specialization of runtime generic functions, and statically dispatched traits are available. Generic structs, closures, and JIT remain future work; see the examples and language reference.
